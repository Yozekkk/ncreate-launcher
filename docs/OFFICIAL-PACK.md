# Официальная серверная сборка NCreate

Единственная официальная сборка лаунчера — `ncreate-server`. Исходный экспорт `NCEA RPG CLIENT.zip` импортирован в отдельный публичный [репозиторий сборки](https://github.com/Yozekkk/ncreate-pack). Лаунчер хранит только адрес канала Stable/Beta; manifest и файлы сборки выпускаются независимо от бинарного приложения.

## Проверенный импорт 1.0.2

Исходный архив: SHA-256 `e2ba21b1f7097261ad063713ba0425c4c6be12a324fc6bf91af6d0127e08d79d`. Он содержит Minecraft 1.21.1, NeoForge 21.1.250, 147 активных модов, конфигурации и небольшой ресурсный пакет NCreate. Из `servers.dat` сохранён адрес `play.ncreate.online:25076`. Архив проверен на абсолютные пути, обход каталогов и символические ссылки. При публикации исключены миры, журналы, crash reports, screenshots, кэши, резервные файлы и данные аккаунтов. Исходный ZIP остаётся у владельца и не входит в Git.

Manifest версии 1.0.2 содержит 718 файлов. Сторонние JAR не размещаются в репозитории: 137 найдены по точному SHA-512 в публичном Modrinth API, четыре берутся из Maven FTB, пять — из CDN опубликованных CurseForge файлов, один — из исходного Modrinth CDN URL экспорта. Для всех 147 перед публикацией выполнены реальные скачивание, сверка размера и SHA-256. Каждая запись мода содержит источник и, если сервис предоставляет их, идентификаторы проекта и версии. Обоснование источников и известный риск доступности одного CDN-файла описаны в [аудите источников](https://github.com/Yozekkk/ncreate-pack/blob/main/docs/SOURCES.md).

Публичный канал: [`channels/stable/ncreate-server.json`](https://raw.githubusercontent.com/Yozekkk/ncreate-pack/main/channels/stable/ncreate-server.json). Файлы конфигураций берутся по неизменяемому Git tag выпуска; Release содержит manifest и `SHA256SUMS.txt`. Пользовательские моды и сохранения не входят в managed-файлы. При обновлении удаляются только файлы, которыми управлял предыдущий manifest; конфликт по пути или изменение managed-файла останавливает операцию. Предыдущая версия сохраняется для отката.

## Повторяемые проверки

Тесты движка покрывают diff v1→v2, добавление, замену и удаление managed-файлов, сохранение пользовательского мода и мира, hash mismatch, отмену, восстановление после прерывания и rollback. Живой тест установки из опубликованного GitHub manifest и запуска полной сборки намеренно исключён из CI из-за объёма загрузок:

```bash
NCREATE_PACK_TEST_ROOT=/tmp/ncreate-pack-smoke cargo test --locked -p ncreate-launcher-core --test live_official_pack -- --ignored --nocapture
NCREATE_PACK_TEST_ROOT=/tmp/ncreate-pack-smoke cargo test --locked -p ncreate-launcher-core --test live_official_launch -- --ignored --nocapture
```

Для запуска нужен Java 21 и графическая Linux-сессия. Публичный бинарный выпуск v0.6.0 Beta включает карточку, установку и обновление официальной сборки; пользователям v0.5.0 требуется однократно установить новый выпуск вручную. Установка NeoForge и игровой процесс сборки 1.0.2 проверены на Linux, но подключение к серверу отдельно не проверялось.
