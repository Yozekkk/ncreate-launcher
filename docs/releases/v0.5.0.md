# NCreate Launcher v0.5.0 Beta

> **Подготовленные заметки, не опубликованный релиз.** На 28 сентября 2026 года исходный код `main` имеет версию `0.2.0`, а публично выпущена только v0.1.0 Beta. Перед выпуском v0.5.0 необходимо обновить версию приложения и проверить новые бинарные файлы Windows и Linux на одном release commit.

Эти заметки описывают возможности, уже подтверждённые в текущем исходном коде. Они не означают, что функции доступны в установщиках v0.1.0.

## Новое

- Библиотека отдельных Minecraft instances: создание, переименование, дублирование, удаление, импорт и экспорт `.mrpack`.
- Установка Minecraft и загрузчиков. В Linux проверены графический запуск Vanilla и Fabric, установка Forge и работа его игрового процесса; Quilt установлен, но его окно отдельно не подтверждено. NeoForge доступен через metadata, без подтверждённого сквозного запуска.
- Публичный каталог Modrinth с поиском модов и сборок. Проверены установка, включение, отключение, обновление и откат отдельного мода, а также импорт публичного modpack.
- Типы аккаунтов Microsoft, Ely.by и Offline. Технические протоколы входа проверены отдельно от успешного входа владельца; публичные скины Ely.by отображаются у offline-профилей.
- Формат официальных NCreate manifests, управление загрузками и механизм обновления с проверкой файлов и откатом на тестовых данных.

## Улучшения

- Страницы Библиотеки и каталога оформлены в стиле NCreate; реклама, Hosting, Friends и вход в аккаунт Modrinth не возвращены.
- Для экземпляров доступны настройки памяти и пути к установленной Java. Совместимость модов проверяется по версии Minecraft, загрузчику и каналу выпуска.
- Токены остаются в системном хранилище учётных данных; импорт файлов проходит через нативный выбор файла и проверку путей и хешей.

## Исправления

- Установка Forge 1.21.1 теперь учитывает формат ожидаемых хешей в upstream metadata. Клиентский patch без отдельной контрольной суммы принимается только с доверенного адреса и с ограничением размера; результат процессора проверяется по SHA-1.
- Проверка обновлений распознаёт импортированные моды по хешу, когда публичный каталог содержит их версии.

## Известные ограничения

- **Minimal, Standard и Ultra пока недоступны:** реальные production manifests NCreate ещё не опубликованы.
- Успешный вход с реальным аккаунтом Microsoft или Ely.by требует проверки владельцем. Синтетические и отрицательные тесты не заменяют эту проверку.
- Автоматическое обновление версии целого modpack и управляемая загрузка Java пока не реализованы.
- Установщик Windows собран в CI, но установка и GUI на физическом Windows-компьютере ещё не проверены.
- Автоматические обновления приложения отключены до настройки подписанных NCreate-релизов.

Результаты исходных проверок и скриншоты: [Stage 2 verification](../STAGE2-VERIFICATION.md). Когда версия 0.5.0 будет собрана и проверена, эти заметки следует сверить с соответствующим commit перед публикацией.
