# NCreate Launcher v0.2.0 Beta

Prepared release notes; this version has not been published as a public release.

## Included in Stage 2

- A custom Minecraft instance library and native creation/import dialogs.
- Public Modrinth mod/modpack search inside the NCreate interface.
- Compatible content installation and mod management.
- Separate Microsoft, Ely.by and offline account providers.
- A versioned official edition manifest and transaction engine.
- Stable/beta edition channel selection.

## Verification and limitations

Minimal, Standard and Ultra remain unavailable until real NCreate manifests are
published. Mock authentication tests do not verify ownership of a real
Microsoft or Ely.by account. Real login requires the account owner's normal
interactive authentication. The application updater remains disabled pending
NCreate signing configuration. Windows CI packaging does not prove Windows GUI
or installation behavior on a physical Windows machine.

See [Stage 2 verification](../STAGE2-VERIFICATION.md) for the tested source-build
behavior, artifacts and remaining limitations before publishing this version.
