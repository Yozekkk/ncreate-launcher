# NCreate Launcher v0.6.0 Beta

This is the first launcher release with the official NCreate server pack. Players can install it from Home, find it in the Library, and launch it without unpacking an archive manually.

## New

- A single official **NCreate Server 1.0.2** pack replaces the Minimal, Standard, and Ultra cards. It includes Minecraft 1.21.1, NeoForge 21.1.250, 147 mods, configurations, and the server address from the supplied pack.
- Installation downloads files from the [public manifest](https://github.com/Yozekkk/ncreate-pack), verifies SHA-256, and prepares Minecraft and the loader. The Library marks it as an official pack while keeping custom instances available.
- Official pack updates download changed files, preserve player worlds and mods, and support rollback. The launcher checks the published manifest for updates.
- Signed launcher updates use GitHub Releases for subsequent versions. Moving from v0.5.0 requires one manual installation of v0.6.0 because v0.5.0 predates the updater.

## Improvements

- An interrupted official pack installation can be resumed from Home or the Library. Recovery adopts only unchanged NeoForge defaults and never silently replaces modified user files.
- Custom instances, the Modrinth catalog, Offline/Microsoft/Ely.by accounts, and Java and memory settings remain available.

## Verification and limitations

- On Linux, the published manifest, all 718 managed downloads, Minecraft and NeoForge installation, and a 45-second game-process launch of pack 1.0.2 were verified. Connecting to the game server was not tested separately.
- Successful sign-in with the owner's real Microsoft or Ely.by account still needs an interactive test. Their protocol checks are separate.
- CI builds the Windows installer, but installation and GUI launch on a physical Windows computer have not been verified. The beta installer has no commercial Authenticode signature.
- Future official pack versions are published separately in [ncreate-pack](https://github.com/Yozekkk/ncreate-pack). The launcher does not invent pack contents when no new manifest exists.
