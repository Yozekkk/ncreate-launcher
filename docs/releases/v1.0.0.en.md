# NCreate Launcher 1.0.0 — Stable Release

The first stable NCreate Launcher release, upgrading directly from 0.6.0 without intermediate Beta or RC releases.

## Interface

- Rebuilt the Vue visual layer around the OneLauncher reference: dark surfaces, typography, spacing, radii, controls, dialogs and interaction states.
- Added top navigation, an account switcher and contextual Settings navigation while retaining NCreate branding and its orange accent.
- Updated Home, Library, Modrinth Content, Accounts, Settings, progress and errors.
- Added locally prepared autumn artwork: a Minecraft scene and an isolated transparent pumpkin. Source artwork remains unchanged. No external seasonal images or remote fonts were added.

## Java

- Requirements come from Minecraft `javaVersion.majorVersion`, merged loader metadata and the official pack manifest.
- Every executable is probed for successful execution, major version and architecture, with a five-second timeout.
- Discovery covers PATH, JAVA_HOME, system locations, Windows Eclipse Adoptium directories and separate NCreate-managed runtimes.
- Missing runtimes are obtained from Mojang. Manifest and file sizes/SHA-1 hashes are verified; staging is transactional and an actual executable probe precedes publication. Unverified downloads are never executed.
- Discovery and automatic preparation share a 120-second deadline. Recovery offers retry, cancellation, the official Adoptium release page and a native `bin/java` / `bin/java.exe` picker.
- Invalid manual runtimes are rejected before saving. Automatically selected Java is no longer persisted as a manual override.
- Loader metadata merging now preserves `javaVersion` overrides.
- Fixed legacy LWJGL launches from non-ASCII Linux paths using a private native-library alias, without moving user files.

## Compatibility

The existing Tauri/Rust backend, Vue IPC contracts, Microsoft/Ely.by/offline accounts, skins, custom instances, NeoForge, official NCreate Server 1.0.2, updates, resume/rollback, Modrinth, Java/RAM settings, deep links and autostart remain in place. Existing user data is preserved. Stable/Beta updater channels remain available; this release is Stable.
