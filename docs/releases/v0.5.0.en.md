# NCreate Launcher v0.5.0 Beta

> **Prepared notes, not a published release.** As of September 28, 2026, `main` is still source version `0.2.0`, and only v0.1.0 Beta has been published. Before releasing v0.5.0, the application version must be updated and new Windows and Linux binaries must be verified against one release commit.

These notes cover behavior already confirmed in the current source tree. They do not imply that the features are present in v0.1.0 installers.

## New

- A library of separate Minecraft instances with creation, renaming, duplication, deletion, and `.mrpack` import and export.
- Minecraft and loader installation. Linux checks opened real Vanilla and Fabric game windows, installed Forge, and observed its game process running. Quilt was installed but its window was not independently captured. NeoForge uses public loader metadata; an end-to-end launch remains unverified.
- Public Modrinth catalog with mod and modpack search. Individual mod installation, enable, disable, update, and rollback were checked, along with the import of a public modpack.
- Microsoft, Ely.by, and Offline account types. Protocol checks are separate from a successful owner sign-in; offline profiles can show public Ely.by skins.
- An official NCreate manifest format, download management, and a file-verified update and rollback engine tested with fixtures.

## Improvements

- Library and catalog pages use the NCreate interface. Advertising, Hosting, Friends, and Modrinth account sign-in remain excluded.
- Instances have memory and installed-Java-path settings. Mod compatibility accounts for the Minecraft version, loader, and release channel.
- Tokens remain in the native credential store. File imports use a native picker and path and hash checks.

## Fixes

- Forge 1.21.1 installation now handles the expected-hash format in upstream metadata. Its client patch lacks a separate checksum, so it is accepted only from the trusted origin under a size limit; the processor output is checked against its SHA-1 hash.
- Update checks identify imported mods by file hash when the public catalog contains their versions.

## Known limitations

- **Minimal, Standard, and Ultra are unavailable:** real production NCreate manifests have not been published.
- Successful sign-in with a real Microsoft or Ely.by account still needs an owner test. Synthetic and negative tests do not replace it.
- Whole-modpack version updates and managed Java downloads are not implemented yet.
- Windows CI builds an installer, but installation and GUI behavior on a physical Windows machine remain unverified.
- Application auto-updates are disabled until signed NCreate releases are configured.

See [Stage 2 verification](../STAGE2-VERIFICATION.md) for source-check evidence and screenshots. Once version 0.5.0 is built and tested, compare these notes with its release commit before publishing.
