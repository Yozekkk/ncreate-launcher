# NCreate Launcher v0.1.0 Beta

The first desktop beta of the official NCreate launcher is here for Windows
and Linux. This release focuses on the launcher interface, saved accounts and
skin previews. Minecraft edition downloads and game launch are coming later.

## What's included

- A dark NCreate interface with orange accents and Russian text.
- Minimal, Standard and Ultra edition cards, with Standard marked as recommended.
- Saved offline accounts with stable UUIDs, account switching and nickname editing.
- Ely.by skin previews, Mojang skin support for Microsoft profiles and a local fallback avatar.
- Microsoft sign-in through the existing Minecraft/Xbox authentication flow.
- Launcher appearance settings and prepared Minecraft settings for future releases.
- Separate NCreate storage, with no migration of existing Modrinth App data.
- Windows x64 installer, Linux x64 AppImage and Debian package.

## Download and install

Choose the package for your system from the release assets:

| Platform | Download |
| --- | --- |
| Windows x64 | `NCreate-Launcher-Setup-0.1.0.exe` |
| Linux x64 | `NCreate-Launcher-0.1.0.AppImage` |
| Debian / Ubuntu x64 | `NCreate-Launcher-0.1.0-amd64.deb` |

On Linux, make the AppImage executable before opening it:

```sh
chmod +x NCreate-Launcher-0.1.0.AppImage
./NCreate-Launcher-0.1.0.AppImage
```

If FUSE is unavailable, use:

```sh
APPIMAGE_EXTRACT_AND_RUN=1 ./NCreate-Launcher-0.1.0.AppImage
```

`SHA256SUMS.txt` contains the checksums for the downloads. The corresponding
GPLv3 source is included as `NCreate-Launcher-v0.1.0-source.tar.gz`.

## Beta limitations

- Minimal, Standard and Ultra are marked **Coming soon**. Downloads, installation and Minecraft launch are disabled in this release.
- Microsoft sign-in reaches the official authentication page. A complete sign-in with a real account, saved Microsoft profile and profile refresh have not yet been verified end to end.
- Ely.by support displays skins for offline profiles; full Ely.by account authentication and in-game skin integration are not included.
- Automatic launcher updates are disabled until signed NCreate updates are configured. Installers are currently unsigned.
- Windows installers were built in CI and their package contents inspected. Windows GUI installation and interaction have not yet been tested on a Windows desktop.
- Russian is the available interface language in this beta.

Linux desktop behavior, offline account persistence, skin previews, settings,
restart and NCreate links were checked in the native application. Frontend and
Rust checks passed, and Windows/Linux package builds completed in CI.
