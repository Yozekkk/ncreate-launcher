# NCreate Launcher v0.6.0 Beta

Первый выпуск лаунчера с официальной серверной сборкой NCreate. Пользователь может установить её из главного окна, увидеть в Библиотеке и запустить без ручной распаковки архива.

## Новое

- Одна официальная сборка **NCreate Server 1.0.2** вместо карточек Minimal, Standard и Ultra. В ней Minecraft 1.21.1, NeoForge 21.1.250, 147 модов, конфигурации и адрес сервера из исходной сборки.
- Установка скачивает файлы из [публичного manifest](https://github.com/Yozekkk/ncreate-pack), проверяет SHA-256 и подготавливает Minecraft и загрузчик. Сборка помечена как официальная в Библиотеке; пользовательские экземпляры Minecraft остаются доступны.
- Обновления официальной сборки загружают изменённые файлы, сохраняют пользовательские миры и моды и поддерживают откат. Статус обновления проверяется по опубликованному manifest.
- Подписанные обновления самого лаунчера через GitHub Releases для новых выпусков. Переход с v0.5.0 требует однократной ручной установки v0.6.0, потому что v0.5.0 выпущена до включения updater.

## Улучшения

- Прерванную установку официальной сборки можно завершить из Главной или Библиотеки. Штатные, неизменённые конфиги NeoForge принимаются при восстановлении; изменённые пользовательские файлы не перезаписываются.
- Сохранены Библиотека пользовательских сборок, каталог Modrinth, аккаунты Offline/Microsoft/Ely.by и настройки Java и памяти.

## Проверка и ограничения

- На Linux проверены опубликованный manifest, загрузка всех 718 управляемых файлов, установка Minecraft и NeoForge, а также 45-секундный запуск игрового процесса сборки 1.0.2. Подключение к игровому серверу отдельно не проверялось.
- Успешный вход владельца с реальным аккаунтом Microsoft или Ely.by всё ещё требует интерактивной проверки. Технические протоколы проверены отдельно.
- Установщик Windows собирается в CI; установка и графический запуск на физическом Windows-компьютере не подтверждены. Текущий beta-установщик не имеет коммерческой подписи Authenticode.
- Публикация новой версии официальной сборки выполняется отдельно в [репозитории ncreate-pack](https://github.com/Yozekkk/ncreate-pack). При отсутствии нового manifest лаунчер не придумывает содержимое сборки.
