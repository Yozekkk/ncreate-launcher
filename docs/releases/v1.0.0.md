# NCreate Launcher 1.0.0

**Stable Release**

Первый стабильный выпуск NCreate Launcher. Прямой переход с 0.6.0 на 1.0.0; промежуточных Beta/RC выпусков нет.

## Интерфейс

- Пересобран визуальный слой Vue: тёмные поверхности, типографика, отступы, радиусы, состояния кнопок, форм и диалогов по визуальной системе OneLauncher.
- Верхняя навигация, переключатель аккаунтов и контекстная навигация настроек сохраняют название, логотип и оранжевый акцент NCreate.
- Обновлены Главная, Библиотека, каталог Modrinth, аккаунты, настройки, прогресс и сообщения об ошибках.
- Добавлены локальные осенние artwork: фон Minecraft и отдельная прозрачная тыква. Оригиналы не изменены; посторонних seasonal изображений и удалённых шрифтов нет.

## Java

- Требования берутся из Minecraft `javaVersion.majorVersion`, итоговой metadata загрузчика и manifest официальной сборки.
- Java проверяется реальным запуском: успешное завершение, major и архитектура. Проверка одного executable ограничена 5 секундами.
- Поиск учитывает PATH, JAVA_HOME, системные каталоги, Eclipse Adoptium на Windows и отдельный каталог NCreate Java.
- Если runtime отсутствует, лаунчер загружает официальный runtime Mojang, проверяет размер и SHA-1 manifest/файлов, готовит его во временном каталоге и публикует только после проверки executable. Непроверенные файлы не запускаются.
- Поиск и автоматическая подготовка ограничены 120 секундами. Диалог предлагает повтор, отмену, официальный сайт Adoptium нужной версии и выбор `bin/java` / `bin/java.exe`.
- Неподходящая ручная Java не сохраняется. Автоматически найденная Java больше не превращается в закреплённый пользовательский путь.
- Исправлено сохранение `javaVersion` при объединении metadata загрузчиков.
- Исправлен запуск старых LWJGL на Linux из каталогов с кириллицей: приватный ASCII alias для native-библиотек без перемещения пользовательских файлов.

## Совместимость

Сохранены Tauri/Rust backend и Vue IPC contracts, Microsoft/Ely.by/Offline, скины, пользовательские экземпляры, NeoForge, установка официальной NCreate Server 1.0.2, обновление, resume/rollback, Modrinth, Java/RAM, deep links, autostart и настройки. Данные пользователя не сбрасываются. Каналы Stable/Beta остаются настройкой updater; текущий выпуск — Stable.
